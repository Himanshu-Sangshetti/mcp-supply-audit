# Code of Conduct

This project follows the spirit of the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone,
regardless of age, body size, disability, ethnicity, gender identity and expression,
level of experience, nationality, personal appearance, race, religion, or sexual identity
and orientation.

## Our standards

- Be kind, be constructive, assume good faith.
- Critique code and ideas, never people.
- Security research is welcome; shaming individual maintainers is not. This project audits
  ecosystems, not people — corpus results must never be used to harass package authors.

## Enforcement

Report unacceptable behavior to himanshu.sangshetti@mem0.ai. Maintainers may remove,
edit, or reject contributions that violate this code, and will communicate reasons for
moderation decisions when appropriate.
